# Working agreements

- Read `docs/WORKOUT_APP_PLAN.md` and the latest iteration in
  `docs/IMPLEMENTATION_PROGRESS.md` before implementation or review work.
- Follow `docs/REACT_WEB_APP_INSTRUCTIONS.md` for React/PWA changes.
- Maintain `docs/IMPLEMENTATION_PROGRESS.md` during every implementation
  iteration. Record findings, changes, validation results, completed work,
  remaining work, and the next action. Close an iteration only after its
  relevant checks pass; distinguish code completion from device validation.
- Update plan/roadmap statuses when evidence or a committed checkpoint changes.
  Preserve historical evidence and clearly label superseded findings.
- Preserve unrelated working-tree changes. Check Git again before reporting a
  checkpoint because the user may commit while work is in progress.
